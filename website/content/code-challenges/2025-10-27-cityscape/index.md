We're launching Cityscape: a community-built, generative artwork made with `p5.js`.

Run it in [your browser](https://aidanwyber.github.io/Cityscape/) and add your own piece of the city via [the GitHub repo](https://github.com/aidanwyber/Cityscape). If you want to join the challenge, check out the details in the GitHub README.md.

## Rules (quick):

- Canvas size: 3840 × 2160 (4K).
- Title of the piece: “Cityscape”.
- Add code, don't remove others' code unless necessary to keep things working.
- Project caps out at 10,000 lines.
- Libraries are allowed (try esm.sh for browser imports).
