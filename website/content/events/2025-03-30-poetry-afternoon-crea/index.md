This time we planned something a little bit different: a **Poetry Afternoon**!

It is going to be a **working session** where we gather to **create** some **digital/machine/robot** **poetry**.

**What is this digital poetry?** You can create an actual poem, or invent a new language, generate an image that resembles a poem, or even a karaoke machine. Feel free to interpret it as you like! It doesn't have to be done by code at all. If you know any poetry nerds, please bring them along!

One little thing, we would prefer if you avoid using LLMs. It is not about asking AI for an amazing poem, but rather about having fun creating and exploring. However, feel free to use AI if you need help with coding.

Some **text** **sources** you can use:

* [Project Gutenberg](https://www.gutenberg.org/)
* [Standard EBooks](https://standardebooks.org/)
* [The CMU Pronouncing Dictionary](https://github.com/Alexir/CMUdict/blob/master/cmudict-0.7b) - A dictionary of English words and their pronunciations, which can be used to generate rhymes.

For **inspiration**, you can check out the following videos:

* [Making machine poetry with train wagons and OC](https://www.youtube.com/watch?v=RESKH-XAv0s)
* [Comedy Writing With Small Generative Models](https://www.youtube.com/watch?v=M2o4f_2L0No)

We're looking forward to seeing you there, or if you can't make it, come say hi on our [Discord](https://discord.gg/qrrKkaM4w3)
